推荐分层如下：

&#x20;

```
一、用户与权限模块：5 张
二、校园基础信息模块：4 张
三、学生分享模块：5 张
四、商家宣传模块：6 张
五、抽奖推荐模块：5 张
六、互动与反馈模块：4 张
七、后台审核与系统模块：4 张
```

合计大约 **33 张表**，你们可以根据实际情况删减到 30 张。

***

# 二、推荐 30 张表版本

## 1. 用户与权限模块

### 1. user 用户表

存学生、卖家、管理员的基础账号信息。

```
id
openid
username
password
nickname
avatar
phone
role
status
created_at
updated_at
```

说明：

```
学生、卖家用微信登录
平台管理员可以使用账号密码登录
```

***

### 2. student\_profile 学生资料表

存学生个性化资料。

```
id
user_id
student_no
school_name
campus
grade
major
gender
created_at
updated_at
```

如果不想涉及学号，也可以去掉 `student_no`。

***

### 3. merchant\_profile 卖家资料表

存卖家身份信息。

```
id
user_id
merchant_name
contact_name
contact_phone
description
apply_status
created_at
updated_at
```

***

### 4. role 角色表

如果你们想做得规范一点，不只用 user 表里的 role 字段。

```
id
role_code
role_name
description
created_at
```

例如：

```
STUDENT
MERCHANT
ADMIN
```

***

### 5. user\_role 用户角色关联表

用户和角色的关联表。

```
id
user_id
role_id
created_at
```

如果你们觉得权限太复杂，可以保留这张表作为“规范设计”，但实际业务可以简单使用。

***

## 6. 抽奖推荐模块

这是项目核心，建议拆细一点。

### 23. lottery\_pool 抽奖池表

这张表很关键，能把学生分享和商家菜品统一起来。

```
id
source_type
source_id
title
canteen_id
category_id
price
score
status
weight
created_at
updated_at
```

其中：

```
source_type = POST / DISH
source_id = student_post.id 或 merchant_dish.id
```

作用：

```
抽奖时不直接查两张表
而是从统一的 lottery_pool 里抽
```

这张表可以作为你们项目的核心设计亮点。

***

### 24. lottery\_rule 抽奖规则表

存不同抽奖模式的规则。

```
id
rule_name
draw_mode
student_ratio
merchant_ratio
min_score
max_price
is_default
status
created_at
updated_at
```

例如：

```
随缘抽：学生分享 70%，商家推荐 30%
口碑抽：学生分享 100%
商家抽：商家推荐 100%
```

***

### 25. lottery\_record 抽奖记录表

记录用户每次抽奖。

```
id
user_id
rule_id
draw_mode
source_type
source_id
condition_json
result_action
created_at
```

结果行为：

```
NONE
ACCEPT
SKIP
FAVORITE
```

***

### 26. lottery\_candidate 抽奖候选表

如果你们做“三选一翻牌”或“候选池”，这张表很好用。

```
id
record_id
source_type
source_id
sort_order
is_selected
created_at
```

比如一次抽奖生成 3 个饭盒：

```
饭盒 A
饭盒 B
饭盒 C
```

用户选中的那个 `is_selected = 1`。

这张表能让抽奖功能看起来很完整。

***

### 27. user\_preference 用户偏好表

用于条件抽奖和默认推荐。

```
id
user_id
default_canteen_id
min_price
max_price
taste_preference
avoid_tags
created_at
updated_at
```

例如：

```
常去二食堂
预算 10-15 元
喜欢微辣、管饱
不吃香菜
```

***
