# 技术栈说明

| 技术 | 版本 | 说明 |

| 技术 | 说明 |

## 项目结构

```
EatNow/
├── backend/              # 后端服务
│   ├── src/main/java/    # Java源码
│   └── pom.xml           # Maven配置
├── frontend-MiniProgram/ # 前端小程序
│   ├── pages/            # 页面目录
│   ├── services/         # 服务层
│   └── manifest.json     # uni-app配置
└── database/             # 数据库脚本
```

## 开发工具

- IDE: IntelliJ IDEA (后端) / HBuilderX (前端)
- 数据库工具: Navicat / MySQL Workbench
- 接口测试: Postman / Apifox
- 版本控制: Git
